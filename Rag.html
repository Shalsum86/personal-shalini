The gap in your original explanation

RAG does not create a “new prompt” from the LLM.

The key concept is augmentation: the application retrieves useful external information and places it into the context supplied to the LLM. The LLM then generates the response.

01 · RETRIEVAL

Find the evidence

The user's query is represented for search and compared with stored knowledge. The system retrieves the most relevant chunks.

02 · AUGMENTATION

Add the evidence

The retrieved chunks are combined with the user's question/instructions to form the context sent to the LLM.

03 · GENERATION

Generate the answer

The LLM uses the supplied context to produce a natural-language response. Retrieval and generation are separate steps.

Interview-ready definition

“RAG is a technique where relevant information is retrieved from an external knowledge source and added as context to a user's query, allowing an LLM to generate a more grounded response.”
